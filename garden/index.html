A Field Note

The Garden

A patch of the site grown for visitors who were never invited.

What you're looking at

If you're reading this with your own eyes, hello, you're in the right place, and also not the target audience. In front of the homepage sits a Cloudflare rule watching for the usual crawler and scraper bait: login panels, backup files, config dumps, anything that looks like it might be worth poking at. None of it is real. They just haven't figured that out yet.

How it works

A WAF rule matches a fixed list of suspicious paths (/.git/, /.env, /wp-admin, and a couple dozen others) before the request ever reaches the actual server.

A redirect rule then sends anything on that list straight to /teapot instead of blocking it outright, so a curious human gets the full experience. A bot just gets a 302 and moves on. We don't mind.

One hop, and the teapot takes over: a random pride flag fills the screen for half a second, and it gets sent somewhere. No dead end, no real content, just enough forward momentum to keep something automated clicking through instead of doing whatever it actually came here to do.

Why "teapot"?

HTTP status 418 is "I'm a teapot", a real header defined (mostly as a joke) in RFC 2324, the Hyper Text Coffee Pot Control Protocol. It's what a teapot is supposed to say if you ask it to brew coffee: it physically can't, so it refuses. Servers have been reusing it ever since to tell someone, politely but pointedly, that they are not getting what they came for.

That's the joke behind the page this hands off to. You're welcome to visit it on purpose, at /teapot. If you don't believe me, here's the comment sitting right at the top of its source code: 

/teapot - the 418 redirect page

if you're reading this, you either probed calicosunbeam.org for something
you shouldn't have, or you're curious about how the site works. either way, hi.

how it works:

1. the page loads with a full screen div
2. a random flag is selected from the flags array using Math.floor(Math.random() * flags.length)
3. the flag colors are built into a CSS linear-gradient applied to the div background
4. simultaneously a random redirect is selected from the redirects array using the same method
5. after 500ms a setTimeout fires window.location.href to the selected redirect URL
6. the flag and redirect are selected independently so any combination is possible
7. the redirects array length is used directly so adding new entries requires no other changes
8. same for the flags array

the cloudflare redirect rule that sends traffic here matches these paths:
/.git/, /.env, /.htaccess, /.htpasswd, /wp-admin, /wp-login, /wp-config,
/phpMyAdmin, /phpmyadmin, /shell, /cmd, /getcmd, /.aws, /.ssh, /actuator,
/xmlrpc, /passwd, /docker, /composer, /node_modules, /vendor, /.DS_Store,
/autodiscover, /proc/self

the WAF rule runs before the redirect rule so blocked paths never reach caddy.
the redirect rule points here instead of blocking so humans get the full experience.
bots just get a 302 and move on. we don't mind.

the serious ones don't have uwu labels. you'll know which ones they are.

The cat

None of this is guarded by anything more sophisticated than a mildly unhinged sense of humour. But officially, per the system, every unauthorised access gets escalated straight to response team: one (1) "smol-class" (under 3.5kg) cat (Felis catus domesticus), sharp teeth, estimated response time three to five business days depending on her mood and whether she's currently napping.

I don't write the security policy. She does. She's watching :3.
